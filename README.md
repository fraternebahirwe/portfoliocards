## ✨ Features

- **Interactive Portfolio Cards:** Displays tech cards highlighting key web development technologies:
  - **HTML:** Markup structure and semantics.
  - **CSS:** Layout styling, custom designs, and responsiveness.
  - **PHP:** Server-side scripting fundamentals.
  - **JavaScript:** Dynamic web interactivity and behavior.
- **Responsive Layout:** Card grid engineered with modern CSS (`portfolio.css`) for smooth rendering across all screen dimensions.
- **Accessible Design:** Uses semantic HTML5 landmarks (`<header>`, `<main>`, `<section>`, `<article>`) and proper image alt descriptions.

---

## 🛠️ Built With

- **HTML5:** Semantic markup & structured content hierarchy.
- **CSS3:** Custom layout styling (`portfolio.css`).
